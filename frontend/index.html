Reads only mail from easyequities.co.za: trade invoices, deposits, withdrawals, EasyProperties orders and corporate actions. Trades, deposits and withdrawals become transactions automatically.

How to get an app password
  1. Turn on 2-Step Verification on the Google account (myaccount.google.com → Security).
  2. Open myaccount.google.com/apppasswords, name it "C-Lab" and create it.
  3. Paste the 16-letter password here. You can revoke it there any time.
